# Brisa Pilates Reformer · Muévete con calma

Web estática publicada con GitHub Pages.

🌐 **https://elenaalcover.github.io/vibe_coding/**

## Estructura

- `index.html` — la web completa (bundle autocontenido: estilos, scripts e imágenes embebidos).
- `.nojekyll` — indica a GitHub Pages que sirva los archivos tal cual, sin procesarlos con Jekyll.

## Cómo actualizar la web

1. Sustituye `index.html` por la nueva versión.
2. Haz commit y push a `main`:
   ```bash
   git add index.html
   git commit -m "Actualiza la web"
   git push
   ```
3. GitHub Pages republica automáticamente en 1–2 minutos.
